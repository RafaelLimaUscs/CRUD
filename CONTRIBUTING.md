Obrigado pelo interesse em contribuir!

Abra uma issue descrevendo o problema ou feature desejada antes de submeter PR.

Execute os testes localmente: ./gradlew test
Submeta um Pull Request descrevendo as mudanças e o motivo.
Mantenha mudanças pequenas e focadas. Obrigado!
